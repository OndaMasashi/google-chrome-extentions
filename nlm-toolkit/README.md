# Gemini Notebook Toolkit

Gemini Notebook（旧 NotebookLM）のノートブック一覧を強化する Chrome 拡張機能です。

対応ドメイン: `notebook.google.com`（現行） / `notebooklm.google.com`（旧・リダイレクト）

## 機能

### 作成日順ソート

標準の「新しい順」は**更新日順**ですが、この拡張で**作成日順**に並び替えできます。

- 並び替えUIの横に **「作成日順 ↓」** ボタンが追加されます
- クリックで降順/昇順をトグル
- 並び替えUIが見つからない場合は、画面右下に**浮動パネル**として表示されます

### タイトル検索（フィルタ）

ノートブックをタイトルでリアルタイム絞り込みできます。

- 検索フィールドにテキストを入力すると、マッチしないカードが非表示になります
- 空にすると全カードが復元されます
- ソートと組み合わせて使えます

## インストール方法

1. このリポジトリをクローンまたはダウンロード
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を ON にする
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. `nlm-toolkit` フォルダを選択

## 技術仕様

- Chrome Manifest V3
- Content Script のみ（バックグラウンドスクリプト・ポップアップなし）
- 特別な権限不要（`notebook.google.com` / `notebooklm.google.com` でのみ動作）

### DOM変更への耐性

Google による DOM 構造変更・リブランドに強い設計を採用しています:

- CSS クラス名に**一切依存しない**
- 日付テキストを複数フォーマットで検出（`2026/08/31` / `2026-08-31` / `2026年8月31日` / `Aug 31, 2026` / `31 Aug 2026`）
- ノートブック URL（`/notebook/UUID`）や `data-notebook-id` でカードを特定。ページ内にリンクが1つも無い構成では、日付テキストのみで探索する縮退モードに切り替わる
- コンテナは「最も多くのカードを直接子要素に持つ祖先」として動的に検出
- 並び替えボタンのラベルは日英の候補リストで照合。見つからない場合は浮動パネルにフォールバック

### 動かないときは

DevTools のコンソールを開き、`[NLM-Toolkit]` で始まるログを確認してください。UI を注入できなかった場合、検出した日付要素数・日付サンプル・ボタンラベル一覧を診断情報として出力します。

なお、一覧の日付表示が「2日前」のような**相対表記**に変わった場合はソート対象を検出できません（診断ログの「日付要素の数」が 0 になります）。
